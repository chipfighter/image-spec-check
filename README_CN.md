# Image Spec Check：生图清单与核对

[English](README.md)

给 Claude Code 和 Codex 用的 skill：生成、修改或核对图片时，把要求整理成一份核对清单；新生成的图或现成的图，都先按清单逐项核对，再交给用户看。

适用场景：对人物长相、服装、发饰、哪只手拿什么、左右方向、道具数量、光线、机位、画风有具体要求；多轮修改同一张图；检查一张现成的图，或一组图之间是否一致；给视频做首尾帧。

## 流程

1. 把用户的要求写进 `清单.md`。每一条都要能看图判断对错，并注明来源（用户 / AI 推测）和要看图上哪个部位。
2. 清单只保留当前版本。用户纠正或撤回某条要求时，下一次生成前先改写或删掉那一条，免得旧说法又被带进提示词。用户指出的问题会写成清单条目，以后每次都查，同一个错误不会第二次漏到用户面前。
3. 左右要同时写明"角色自己的左右"和"画面的左右"，换机位后重新换算。
4. 画风类要求分三部分写：要有什么、不能有什么、看哪些部位。
5. 只改局部时，在当前底图上修图；机位、景别或姿势变化大，或者同一处修了两次还不对，就重新生成，底图只当参考。
6. 每张图出来后，由没看过提示词的检查者按原分辨率裁出局部，逐条判为通过、不通过或看不清。判"通过"时，必须说出在哪个具体位置看到了什么。裁出的局部不放大：放大不会多出细节，只会变糊、多花 token。
7. 每次出图后都自动核对，不用用户要求。只有用户明确说是草稿、不用查时，才只快速看手、持物、左右、数量这类最容易错的项；修图后，细查这一轮改过的条目和最容易错的项，其余部分和上一版对比；重新生成的图，所有条目都查。
8. 检查者可以用子代理来跑，推理强度用低档就够，因为核对主要靠看。模型可以比主代理低一档，但要能看清细节。
9. 同一条连续两次不通过就停下，交给用户处理，不再换个说法重试。
10. 省 token 由 AI 自己做到，不要求用户做什么：看裁切图交给子代理，免得图堆在主对话里；能合并的步骤合并；核对记录只往后追加，不整份重读。

动作是否自然、表情是否到位、整体好不好看，由用户判断，skill 不替用户下结论。

## 安装

Claude Code：

```bash
git clone https://github.com/chipfighter/image-spec-check ~/.claude/skills/image-spec-check
```

Codex：

```bash
git clone https://github.com/chipfighter/image-spec-check ~/.codex/skills/image-spec-check
```

裁切局部需要 `ffmpeg` 和 `ffprobe`。

## 测试情况

2026 年 10 月，在 Codex（gpt-6.1-sol）里对同一张宋代女子插画做了 5 轮修改测试：

- **做得好**：改过的要求不留旧条目；正面和背面两种机位，左右都换算正确；局部改动用修图，换机位改为重新生成；看不清的地方和出图失败都如实报告。
- **没做到**：画风不对，检查者连续 4 轮都判了通过，直到用户明确指出才改对。之后补了两条规则，还没重新测试：画风类要求写清"要有、不能有、看哪里"；判"通过"必须说出具体位置和看到的东西。
- **没测到**："同一条两次不过就停"的规则，以及首尾帧衔接的核对。
- **耗时**：每轮约 10–20 分钟，其中一部分是网络重试，独立检查者也会多花时间。

当前为实验版本。
